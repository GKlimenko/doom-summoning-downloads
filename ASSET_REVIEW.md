# Asset distribution review

Before public distribution, verify redistribution permission for user-supplied Thor, Doom, mask, witch, Stormbreaker, Sentinel and Bifrost sword models, plus the Meshy throne under the account/license used to generate it. Some original creator/source information is missing from the project manifest. Marvel character and setting credits do not themselves grant rights.

The newly uploaded RigModels OBJ is NOT integrated into the current APK. Its included license specifies personal/student use and requires a Premium membership for commercial use; do not publish that source archive in a public repository without checking the applicable terms.

Keep purchased Unity asset source files in a private repository, subject to each license. Do not upload `.env*`, API keys, signing keys, node_modules, Unity caches, Library, Temp, Logs, or generated build directories to a public source repository.

Recorded music: Scott Buckley CC BY 4.0, attribution and adaptations in CREDITS.txt. Kenney and the recorded Freesound creature sample are credited CC0. Preserve bundled font and other notices.
