# Doom Summoning — Quest prototype

Unofficial fan-made mixed-reality experience for Meta Quest 3. Not affiliated with or endorsed by Marvel.

## Install
1. Download `DoomSummoning-0.39.2-Quest.apk` and `SHA256SUMS.txt` from this release.
2. Enable Developer Mode on your Quest, connect it to a computer, and accept USB debugging.
3. Install the APK using Meta Quest Developer Hub or SideQuest.
4. Open Doom Summoning from the headset’s sideloaded-app/Unknown Sources library. Allow requested hand-tracking, body-tracking and spatial-data permissions for the corresponding features, and scan your play space.

Requires a Quest headset; this APK does not run on phones, Windows, or Snap Specs. Use a clear play space. Same-room multiplayer is an experimental prototype and has not yet been validated with two headsets.
